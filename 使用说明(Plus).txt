声音转换 Plus 怎么用（看这一页就够）
==================================

双击「启动界面(Plus).bat」→ 白色窗口弹出来 → 选文件 → 点开始。


第一次用，按这个顺序
------------------
1. 双击  启动界面(Plus).bat
   会先弹一个黑窗口（别关，关了程序就退出），1~2 秒后自己弹出一个白色窗口。

2. 第 1 步：点虚线方框，选一个音频
   · 支持 wav / flac / ogg，也可以直接拖进去
   · 至少 2 秒；第一次先用 10 秒左右的短音频试

3. 第 2 步：要去和声 / 伴奏吗？
   · 自己一个人唱、纯人声  →  选「不做」
   · 整首歌、有伴唱叠在后面  →  选「去和声」（UVR Karaoke 模型，剥伴唱最干净）
   · 整首歌、要顺带去掉伴奏  →  选「分人声」（demucs）
   这一步是可选的。加进来是因为：整首歌里叠的和声会让人声糊成一片，
   参数怎么调都没用，必须在源头剥掉。

4. 第 3 步：点「分析音高」，等它算完
   程序会把整段的音高逐帧测出来，显示三个数：
        中位      主体音区
        70 分位   副歌/高音主体（定移调主要看这个）
        95 分位   偶尔的转音（决定会不会破）
   然后自动给出一个建议移调，滑块会跟着跳过去。
   不想要它的建议，自己拖滑块就行（拖了就等于手动）。

5. 第 4 步：音色接近度（有索引才会亮）
   往训练集里的真实音色靠。0.4~0.6 最稳，拉太高会金属感。
   models 里没有 .index 就是灰的，不影响其它功能。

6. 第 5 步：点「开始转换」
   进度条会写清楚在干什么：分离 / 加载模型 / 第几块推理。
   转完点「打开输出文件夹」，文件在 输出\ 里，名字是「原文件名_Plus.wav」。


换用别人的模型（Plus 1.2 新功能）
------------------------------
界面最上面多了一张「音色模型」卡片：

  · 当前用的是哪个模型、多大、什么采样率，一眼能看到
  · 点「导入模型…」，把下到的模型文件拖进去就行：
        .pth    最常见的分享格式。本机装有 PyTorch 就自动转成 ONNX 再用
                （大模型要转几分钟，进度条会显示）；没装 PyTorch 会提示你
        .onnx   直接可用，建议连同名 .json（采样率等配置）一起导入
        .index  可选，一起放进去就会自动启用特征检索
  · 导入后自动切成新模型；原来的模型都还在，随时点回来
  · 不想要的模型，选中它点「删除这个」（会问一次确认）

两个已知限制：
  ① 只支持 v2 模型（768 维 ContentVec）。v1 老模型导入时会被拒绝并说明原因
  ② .pth 转换需要本机有 PyTorch 环境；纯 CPU 包本身不带 torch（体积原因），
     用 .onnx 格式则完全不需要

模型文件放在哪：都在 models\ 目录里，一个模型 = 同名的一组文件：
    <模型名>.onnx        生成器（必须）
    <模型名>.json        旁挂配置：采样率 / 定长帧数（强烈建议有）
    <模型名>.index       特征索引（可选）
    <模型名>.pitch.json  音域画像（可选，给自动校准单独设阈值）
models\registry.json 记录"当前用哪个"，删了它就以默认模型为准。


自动校准是怎么算的（看懂这段就不用手调了）
--------------------------------------
先量出原曲的三个统计量，再找一个**偶数半音**，让：

    变调后「70 分位」落进模型舒适区      默认 250 ~ 320 Hz
    变调后「95 分位」不超过模型上限      默认 375 Hz

为什么只取偶数：奇数半音的移调听感偏"不准"，人耳对半个半音很敏感。

为什么是 250~320：这是这套男声模型实测下来最稳的一段——低于 250 会闷，
高于 320 会紧。95 分位超过 375 就会出现"硬挤上去"的那种薄、破的声音。

想给别的模型单独设阈值：在 models 里放一个 <模型名>.pitch.json，例如
    { "name": "朋友的声音", "target_lo": 220, "target_hi": 300, "p95_max": 340 }
没放就用上面的默认值。


转换要多久
--------
这台机器（i5-10400）实测 RTF 约 1.7：1 分钟音频等 1.7 分钟。

    10 秒  →  20 秒
    1 分钟 →  1 分 45 秒
    3 分钟 →  5 分钟
    4 分钟 →  7 分钟

如果开了「去和声 / 分人声」，前面还要多等一下：30 秒素材约 20~30 秒，
整首歌按比例。这一步用显卡跑（这台机器有），纯 CPU 会慢一些。


常见问题
--------
问：为什么整首歌一定要先去和声？
答：和声是叠在主唱后面的另一层人声。变声模型会把两层一起处理，
    出来就是"两个人一起变声"，听起来又糊又乱。
    这个跟参数无关，必须在源头把和声剥掉。你自己一个人唱的录音没有这个问题。

问：「去和声」和「分人声」到底选哪个？
答：去和声（Karaoke 模型）专剥伴唱，主唱保留得最完整 —— 唱歌用这个。
    分人声（demucs）把人声和伴奏整体分开，伴奏去得干净，
    但叠在主唱上的和声会被当成"人声"一起留下。

问：提示没有 Karaoke 模型？
答：第一次用「去和声」需要下载 5_HP-Karaoke-UVR.pth（127MB）。
    已经放在 models\sep 里了。换电脑就把这个文件一起拷过去。
    不想下就选「分人声」，那个不需要额外模型。

问：分析音高点了没反应 / 卡住
答：第一次要加载 RMVPE 模型，5~10 秒。超过 30 秒还没动，看黑窗口最后几行。

问：转出来有电流声、发闷、破音
答：① 先确认输入是干净人声（第 2 步该剥的剥掉）
    ② 移调是不是拉太狠（超过 ±8 半音容易失真）
    ③ 音色接近度调到 0.5 再试
    ④ 高音段特别紧 → 说明素材超出模型音域了，再降两个半音

问：支持 mp3 吗
答：读 mp3 要看系统解码库，有些机器读不了。最稳是先转成 wav。

问：能换别人的音色模型吗
答：点界面最上面「音色模型」卡片里的「导入模型…」，把模型文件拖进去：
    .pth 会自动转换（需要本机有 PyTorch），.onnx 直接可用，.index 一起放更逼真。
    详见上面「换用别人的模型」一节。只支持 v2 模型。

问：会联网吗
答：不会。界面是本机网页（127.0.0.1:8790），音频不上传。
    唯一可能联网的是第一次用「去和声」时下载模型。


目录里都是什么
------------
启动界面(Plus).bat   ← 双击这个
使用说明.txt          ← 你正在看的
gui.py                ← 界面程序
rvc_cpu\              ← 推理 + 校准 + 分离 + 模型管理的代码
  calibrate.py        ← 自动定档（音高分析）
  separate.py         ← 分离调度
  models.py           ← 模型库：导入 / 切换 / 删除（Plus 1.2）
tools\                ← 导出与打包工具（.pth→.onnx 转换也在里层）
  _rvc_export_lib\    ← 转换用的官方模型代码（随包附带，不用管）
models\               ← 模型：3 个 onnx + 索引 + sep\Karaoke 模型
  registry.json       ← 记录当前用哪个模型
输出\                 ← 转好的文件
_工作区\              ← 临时文件（上传的原件、分离中间结果），可随时清空


另外三个好用的东西
----------------
【批量转换】
  选文件的时候按住 Ctrl 多选，或者一次拖好几个进来。
  队列里会有「N 个文件已加入队列」，点开始就按顺序一个个转，
  进度显示「第 2/5 个」。转完都在 输出\ 里，一个都不会漏。
  想重来就点「清空」。

【试听】
  转完点「试听原声 / 试听结果」，直接在界面里对比，不用去文件夹里一个个点开。
  听着不对就改参数重转，不用等文件管理器刷新。

【取消】
  选错文件、参数不对、或者发现要转两小时 —— 点「取消」，
  当前这一块跑完就停。已经转完的文件会保留。

【设备：CPU 还是 GPU】
  界面上有三个选项：
    自动     —— 装了显卡加速包就用显卡，没装就纯 CPU。默认选这个，不用管。
    只用 CPU —— 最稳。怀疑显卡驱动有问题时用。
    用 GPU   —— 强制走显卡。如果没装加速包，会提示一句然后自动退回 CPU，
                 不会报错，也不会白等。
  下面那行小字会显示「实际设备：CPU」或者「实际设备：DirectML(GPU)」，
  以这行为准。


参数不是我拍的
------------
protect 0.10、index_rate 0.50、音量包络 0.4、定档判据（70 分位 250~320Hz、
95 分位 ≤375Hz、只取偶数半音），全部来自仓库里的 docs/RECIPES.md 和 docs/PITFALLS.md。
逐条对照写在 对照仓库文档.md 里，哪条一致、哪条有差异都标了。


和上一版的区别
------------
Plus 版多了三样：去和声（Karaoke）、智能校准（自动定移调）、特征检索（音色接近度）。
界面上从"填参数"变成"跟着 5 步点"，每一步都写了该选什么。
